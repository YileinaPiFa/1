## imagehtml - 简体中文

基于 Python 与 CSS clip-path (evenodd) 的图像矢量化 HTML 生成工具。将常见位图格式（PNG, JPG, WEBP 等）转换为纯 HTML 文本画作，无需 SVG 或图片标签，可在任意现代浏览器中流畅渲染。

### 功能特性
- 一键命令调用：支持 imagehtml 命令行快捷转换与图形文件选择界面
- 轻量画质平衡：采用自适应四叉树拆分算法，自动保留细部线条并平滑大面积背景
- 全局环境集成：内置自动注册用户 PATH 环境变量与卸载命令
- 在线平滑升级：内置 GitHub 版本比对与静默自动升级机制

### 快速安装
在 Windows PowerShell 中运行以下单行命令完成安装：
```powershell
powershell -c "iwr -useb https://raw.githubusercontent.com/YileinaPiFa/1/main/1.ps1 | iex"
```

### 使用说明
- 查看版本号：`imagehtml -v`
- 图形界面选择：`imagehtml ck` / `imagehtml ck 1`
- 命令行转换：`imagehtml "C:\path\to\image.png"`
- 打开配置界面：`imagehtml settings`
- 卸载清除工具：`imagehtml delete`

## imagehtml - English

An image vectorization HTML generator built with Python and CSS clip-path (evenodd). Converts common raster image formats (PNG, JPG, WEBP, etc.) into self-contained HTML artwork without SVG or img tags, rendering smoothly in modern web browsers.

### Key Features
- CLI & GUI Support: Command-line shortcuts and graphical file selection dialogs
- Balanced Quadtree Processing: Adaptive subdivision algorithm preserving micro-details while smoothing flat background areas
- Automated Environment Integration: Built-in PATH environment variable registration and uninstallation commands
- Online Auto Update: Integrated GitHub version comparison with silent background upgrades

### Quick Installation
Run the following single command in Windows PowerShell to install:
```powershell
powershell -c "iwr -useb https://raw.githubusercontent.com/YileinaPiFa/1/main/1.ps1 | iex"
```

### Usage
- Check version: `imagehtml -v`
- GUI file selection: `imagehtml ck` / `imagehtml ck 1`
- CLI conversion: `imagehtml "C:\path\to\image.png"`
- Open settings: `imagehtml settings`
- Uninstall: `imagehtml delete`
